# proHUB — installation steps for your Wix site

**File:** prohub.html  (single file, nothing else to upload)

## Add it to Wix
1. Open your site in the Wix Editor (or Wix Studio).
2. Go to the page you want proHUB on — production desk, or a members-only page.
3. Click **Add Elements (+)** on the left, then **Embed Code**, then **Embed HTML**.
4. Choose **Enter Code**, select the **Code** option, and paste the whole contents of prohub.html.
5. Click **Apply**.
6. Drag the element into place and stretch it to the full width of your page.
7. Give it plenty of height — **at least 1200 px** — proHUB opens nine desks inside that box and scrolls internally. If it looks short, the box is too short.
8. Repeat for the mobile breakpoint: check the element is full width and at least 1200 px tall there too.
9. **Publish**, then open the published page (not the editor preview) to test. The editor canvas does not run every script.

## First run
- Press **Desk menu > Pull from preHUB** if you already transmit scripts from preHUB, or
- **Desk menu > Import a script file** (Final Draft .fdx, Fountain, PDF, plain text or JSON), or
- **Desk menu > Paste script text**.

Then: Script tile > check the tags > Stripboard tile > **Auto-board** > Call sheets tile > **Print sheet**.

## Getting your work in and out
- Everything saves in the browser on that device.
- **Storage vault > Export project file** gives you a single .json holding the whole show.
- **Storage vault > Restore project file** brings it back — on this machine or another.

## Good to know
- Nothing is uploaded, nothing is tracked, and there is no account.
- The only time proHUB ever reaches the internet is if you press **Fetch weather & hospital** on the Call sheets tile, or import a PDF newer than your browser's cached reader. Everything else works offline.
- Browser pop-up boxes are blocked inside a Wix embed, so every prompt in proHUB is its own in-app panel.
- If your Wix setup blocks storage between pages, the hand-offs fall back to a copy-to-clipboard panel — and the project file always works.
